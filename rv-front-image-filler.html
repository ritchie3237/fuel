Front-Image Filler

Fills column J (“Front view”) of a Tiptoi order Excel with each product’s front pack shot — automatically, from the article number. Fully offline.

1 · How it works

Ravensburger’s public image CDN serves every product’s front pack shot at a fixed address built from the 5-digit article number inside the EAN — e.g. EAN 4005556​00168​2 → cdn.ravensburger.de/images/produktseiten/240/00168.jpg. This tool reads each row’s EAN, builds that link, and writes an Excel =IMAGE(…) formula into the Front view column, so Excel shows the picture in-cell. In German Excel this same formula appears as =BILD(…). Your Side view column K and everything else in the file are left untouched.

It first checks whether each image actually exists on the server. Only products with a published picture are filled; the rest are left empty — no #BLOCKED error — ready for you to paste a screenshot. (Re-running also clears any old error formula from a previous version.)

Requires: Excel that supports the IMAGE() function (Microsoft 365), and internet access while this tool runs (to check the images) and in Excel (to display them). Nothing is uploaded anywhere — the file is rewritten locally in your browser.

01Before you start

There are two separate files, each a single web page you open in your browser (recent Edge, Chrome or Firefox):

  • Shelf Planner (ravensburger-shelf-planner.html) — turns an order list into a true-to-scale shelf plan and an editable Excel.
  • Front-Image Filler (rv-front-image-filler.html) — fills the “Front view” column of an order Excel with product pictures.

Save each file anywhere and double-click to open. Nothing installs, nothing is uploaded — everything happens on your machine. When you first open the planner it loads a small BRIO Flora demo so you can try every button safely.

Your work is remembered in that browser on that computer. To move it to another PC, use Backup to file / Restore file (see Projects).

02Set up your shelves top ↑

In the planner, section 3 · Store shelves & theme areas is where you build your fixture:

  1. Each row is one physical shelf: give it a fixture template (size / number of levels) and a theme area name (free text — e.g. Kids, Me Time, Fan Highlights).
  2. Add as many shelves as you need with + Add shelf. Shelves that share a theme name form one area.
  3. Pick the area you want to see from the Theme area dropdown above the planogram.
Name shelves to match your Excel tabs. When you upload a workbook, each tab’s products go to the shelf area with the same name. Spaces, underscores and capital letters don’t matter — a tab called Me_Time lands on a Me Time shelf. So the rule is simple: create a shelf area named like the tab, and its products land there automatically.

03Load your order Excel top ↑

Use Load order file (.xlsx / .csv) in section 1. The tool reads one row per product: EAN, article number, title, order quantity, package width×height×depth, and category. It understands German or English headers.

Product pictures in the order file

Photos embedded in the sheet are read by column heading:

  • Front view → column J
  • Side view → column K
  • Open / unpacked → column L

Both floating pictures and Excel’s “image in cell” photos are picked up. Front always uses its own column-J picture and never borrows the side one.

A product with no size given is placed in “Held aside” rather than guessed — type its dimensions in and it joins the shelf. Uploading a new order replaces the current products by default (your saved projects are untouched); choose Cancel on the prompt to add instead.

04Arrange & edit the shelf top ↑

Press ⚙ Generate layout and the tool arranges the active area to the house style: up to two different products face-out in the centre, the rest turned sideways to fill the shelf, best-sellers and larger items nearer eye level.

  • Drag a product to another level or shelf.
  • Click a product to change its facings, switch it between front / side / open view, duplicate it, or remove it.
  • Your hand edits stick — only pressing Generate re-arranges from scratch.

05Shelf banners & icons top ↑

Click the coloured banner above any shelf to set that one shelf: pick its category / icon, type custom text, or make it a plain panel. Special Offer shows red; the others blue. Each shelf is independent.

Adding an icon for a new category

The built-in icons (Kids, Toddler, Me-Time, Fan-Highlights, Games Party, Explorers, Special Offer, BRIO Flora) appear automatically from the area name. If you invent a new category, open Category icons in the top bar and add a row: type the category name and choose which icon it should use. From then on any shelf in that area shows it automatically. Use Export / Import to share your list with a colleague.

A brand-new picture that isn’t in the icon list yet needs a developer to add — but you can always point a new category at the closest existing icon yourself.

06Save & reopen projects top ↑

Click ★ My projects (top bar) to keep a shelf setup and come back to it:

  1. Build your shelves, type a name (e.g. Kids · tiptoi) and press Save.
  2. Saved projects are listed newest first, with how many shelves / products each has and when you last edited it.
  3. Press Open on any of them to load it back. Save as new keeps the current one and stores a separate copy.

Uploading a new order never deletes a saved project, so you can build Kids, save it, then start Toddler without losing Kids. For a copy outside the browser (another PC, a backup), use Backup to file and Restore file.

07Export for the store top ↑

  • Export Excel — the shelf-assignment workbook (shelf, level, article, product, view, facings, position, theme, plus a summary).
  • Export PNG or Print — the visual planogram for the stocking team.

08Filling product images (Image Filler) top ↑

Open rv-front-image-filler.html and pick your order Excel. For each product it builds the picture link from the EAN, checks the image actually exists, and writes it into the Front view column as an =IMAGE(…) formula (shown as =BILD(…) in German Excel). Then press Download filled Excel.

  • Products with a published picture are filled automatically.
  • Products without one are left empty — no error — ready for you to paste a screenshot. Click the empty cell and use Insert ▸ Pictures ▸ Place in Cell. Cells you fill yourself are never overwritten if you run the tool again.
Requires Excel 365 (the IMAGE / BILD function) and internet, so the pictures can load. The Side-view column is left for you to fill.

09Adding a new brand of images top ↑

The Image Filler has an Image sources table (section 2) that you can edit yourself — one row per brand:

The template uses placeholders the tool fills in for you:

  • {art5} — the 5-digit article number inside the EAN (what Ravensburger’s server uses).
  • {ean} — the whole barcode, for a brand whose images are named by full EAN.

Add a row with + Add brand, fill in the prefix and template, and that brand’s products get pictures too — no help from IT needed. Export / Import shares the table with colleagues. If you don’t yet know a brand’s URL pattern, ask whoever manages that brand’s image server (PIM) for a permanent link by article number, then paste it in.

10Good to know / FAQ top ↑

Some products have no picture

Only items whose image is published on the public server can be filled automatically. The rest are left empty on purpose — add a screenshot as above. The clean side view generally isn’t on the public server at all; that needs a permanent PIM link (in progress).

An item shows an error in Excel (e.g. #BLOCKED / #BLOCKIERT)

That happens when a picture link can’t be reached. The current Image Filler avoids it by only writing links that work and clearing old broken ones — re-run your file through the latest version and the error disappears.

Products landed on the wrong shelf

Check that a shelf area exists with the same name as the Excel tab. If no area matches, the products fall onto the area you’re currently viewing. Create the matching area (spaces / underscores / case don’t matter) and re-upload.

Is my data sent anywhere?

No. Both tools run entirely in your browser. Files you open are processed locally; nothing is uploaded.
